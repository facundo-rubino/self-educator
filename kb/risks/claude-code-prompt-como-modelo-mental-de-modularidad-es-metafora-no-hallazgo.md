## What it is
El salto desde el diseño interno de un asistente de programación hacia un modelo prescriptivo para «enseñar y gestionar» es decoración analógica. La evidencia solo atestigua un artefacto de producto; no transfiere a práctica de liderazgo, estimación, secuenciación ni docencia.
